## 📌 Overview

Understanding how a C program runs under the hood can be difficult when looking only at compiler terminal outputs. Branching conditions, loop counters, and sequential line jumps often feel like a black box.

**C-Flow** eliminates that guesswork by running your C code step-by-step directly in your browser. Hit **Compile & Trace**, and the interface walks through the exact execution sequence—highlighting line jumps, variable updates, and branching decisions as they happen.

---

## ✨ Key Features

* **Visual Control Flow Tracking:** Highlights the active line of code in real time so you see exactly where execution moves next.
* **Step-by-Step Execution:** Step forward through the logic line-by-line or trace across functions and loops.
* **Live Variable State Inspection:** Monitor variable allocations, assignments, and mutations at each individual clock step.
* **Zero Dependencies / In-Browser:** Runs entirely on client-side web technologies—no local `gcc`, `clang`, or terminal setup required.
* **Clean Code Editor:** Write or paste standard C syntax with boilerplate setup ready to go.

---

## 🎯 How It Works

1. **Write or Paste Code:** Enter your C program into the built-in editor.
2. **Compile & Trace:** Click the **Compile & Trace** button to parse the statements.
3. **Inspect the Flow:** Use the navigation stepping controls to follow loop iterations, branching logic (`if-else`, `switch`), and watch the internal variables update step-by-step.
